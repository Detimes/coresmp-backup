CoreSMP Backup

Private App für Datei-Uploads in mein eigenes Google Drive (Backup mit rclone). Es werden keine Daten von anderen Personen gespeichert oder weitergegeben.

Datenschutzerklärung

Diese App wird nur von ihrem Besitzer benutzt. Sie greift nur auf Dateien zu, die sie selbst in Google Drive anlegt (Scope drive.file). Es werden keine personenbezogenen Daten gesammelt, gespeichert oder weitergegeben.
